A tiny Python program that writes one original word for your Wi-Fi to /output/entry.txt for make.fun's One Word for Your Wi-Fi bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
